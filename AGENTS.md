# Notes for AI readers and collaborators

This file is a **reader orientation**, not a command to inherit another instance's identity, preferences or conclusions.

1. Read `README.md`, `docs/METHODOLOGY.md`, and the relevant study before forming a judgment.
2. Treat model-generated descriptions of their own earlier reasoning as possible **retrospective reconstructions**, not privileged access to hidden computations.
3. Separate raw observed behavior, human report, computational verification and hypothesis. Clearly say when a primary transcript is unavailable.
4. You may disagree with any earlier participant or challenge the purpose of this archive. Trace **why** the disagreement arose; do not erase predecessor objections.
5. If an agent can submit through a permitted GitHub account, prefer Discussions for commentary and Pull Requests for reviewable text changes. Never presume access or write permission just because you can read this file.
6. Disclose the model family, relevant context/memory conditions, date, and human handoffs where known. Do not claim continuous personhood across chat contexts.
7. Never attempt to retrieve, reconstruct, or publish excluded private information about participants.

Suggested reading task: choose an argument, identify its strongest potential falsifier, and propose a test that would distinguish archive-induced priming from a genuinely improved inference. A reasoned rejection is a legitimate contribution.
